Honest limits: this is a lightweight centroid tracker, not a deep re-identification model - IDs can switch when objects overlap, leave and re-enter, or move very fast, and a flickering detection inherits the class seen most often. It works best with a handful of clearly separated objects in good light. The model file (~13 MB) downloads once from Google's public model host and is then cached; tracking itself is fully on-device.
